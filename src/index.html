Glosario técnico +

Delta-v es el cambio de velocidad disponible para una maniobra. Apogeo es el punto más lejano de una órbita. Perigeo es el más cercano.

¿Aeronáutica o astronáutica? +

La aeronáutica estudia vehículos dentro de la atmósfera. La astronáutica diseña vehículos para el espacio. La astrodinámica calcula cómo se mueven ambos sistemas.

Satélites y comunicación +

Los satélites observan la Tierra, sincronizan navegación y conectan continentes. Su órbita determina la cobertura, el retraso y la energía necesaria.

Materiales de una nave +

Titanio para estructuras resistentes, aluminio para reducir masa, compuestos de carbono para rigidez y cerámicas térmicas para el reingreso.

Roles en una misión +

Ingeniería de sistemas, control de vuelo, aviónica, propulsión, ciencia de datos y operaciones trabajan como un solo organismo.

Científicas que abrieron camino +

Katherine Johnson calculó trayectorias orbitales; Annie Easley desarrolló software y modelos para sistemas energéticos espaciales.
